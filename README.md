# franciscoarevalo.net

Personal website of Francisco Arevalo — Telecom Project Manager & Network Engineer.

**Live:** https://franciscoarevalo.net

## Tech Stack

HTML, CSS, JavaScript — no build tools required. Hosted on GitHub Pages.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `styles.css` | All styles (dark + light theme via CSS custom properties) |
| `main.js` | Theme toggle, back-to-top, mobile nav |
| `favicon.svg` | Signal tower icon |
| `resume.pdf` | Downloadable resume |

## Editing

Edit `index.html` to update content. Edit `styles.css` to change colors or layout.

## Deploying

Push to `main` branch — GitHub Pages deploys automatically. No build step needed.
